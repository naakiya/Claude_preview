TAB

フレットはドロップD（6弦D）として書いています。実際は全弦を半音下げるので、6弦から C# G# C# F# A# D#。数字をタップするとそこへ移動します。

4つのフォーム

左がこの動画で鳴っているコード、下が押さえる形（ドロップDでの名前）です。白丸は飾りで入る音です。

練習の順番

  1. チューニング：全部の弦を半音下げ、さらに6弦だけもう1音下げます（6弦から C# G# C# F# A# D#）。動画と合わせないなら、普通のドロップD（D A D G B E）でも同じ形で弾けます。
  2. 形を覚える：上の4つを押さえて、1つずつ全部の弦をゆっくり鳴らします。D♭（D形）だけ6〜9フレットの高い位置、ほかは2〜4フレットです。
  3. 親指だけ：低音は各コードの「1拍目」と「その16分3つ後」の2回です（ドン・・ドン）。D♭は6弦開放、E♭は6弦2、Fmは6弦4、A♭は5弦開放。
  4. 50%で1小節ずつ：くり返しを「1小節目」にして、TABの音を鳴らしながら合わせます。
  5. つなげる：「1〜2小節」→「全部」→ 速度を 70% → 85% → 100% に。最後のA♭は最後の和音を伸ばして終わります。

もっと簡単に弾くなら

普通のチューニングで カポ1 にすると、C → D → Em7 → G の形で同じコード（D♭ → E♭ → Fm → A♭）になります。Cadd9（x32033）・D（xx0232）・Em7（022033）・G（320033）を、同じ「ドン・・ドン」の親指＋アルペジオで弾けば雰囲気が出ます。

どうやって調べたか

  • 確度 高 コード進行とテンポ：音声のピッチ解析（basic-pitch）と、音の成分（クロマ）の分析から。D♭ → E♭ → Fm → E♭ ｜ D♭ → E♭ → Fm → A♭ の4小節を、♩=81 の16分音符で弾いています。このTABを合成した音と原曲を比べると、和音の一致度は半小節ごとに 0.83〜0.94 でした。
  • 確度 高 低音：一番低い音が C#2（ふつうのチューニングより低い）なので、6弦をC#まで下げたチューニングと判断しました。スマホのマイクは低音が弱いので、解析では1オクターブ上に出ていた音を直しています。
  • 推定 どの弦・何フレットか：映像で12フレットのドットを目印に手の位置を数えました。D♭のときは手が6〜9フレットあたり、ほかは低い位置です。ただし指先が画面の端で切れているので、弦の選び方は「鳴っている音が一番自然に出る押さえ方」で決めています。
  • 推定 高い音（1弦9フレット）：3小節目の頭と最後の和音で聞こえる高い C の音です。最後の和音では手が低い位置にあるので、本当はハーモニクスかもしれません。届かなければ省略してください。
