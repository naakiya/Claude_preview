# sad music pt.02 TAB

「making sad music for happy people pt.02」（アコギ指弾きの短いクリップ）の耳コピTABです。
`index.html` を開いて画面収録（.mov）を読み込むと、再生に合わせてTABのカーソルが動きます。動画なしでもTABの音で練習できます。

- キー：A♭ / ♩=81 / 4/4（16分音符の指弾き）
- チューニング：ドロップD を半音下げ（6弦から C# G# C# F# A# D#）。TABのフレット番号はドロップDとして書いています
- 進行：D♭ → E♭ → Fm → E♭（→A♭）｜ D♭ → E♭ → Fm → A♭（ドロップDの形では D → E → F#m → E ｜ D → E → F#m → A）
- 簡単版：普通のチューニングでカポ1、C → D → Em7 → G

コード・テンポ・低音は音声解析で確認しました。どの弦・何フレットで弾いているかは、映像の手の位置を参考にした推定です。
動画ファイルは端末の中だけで再生され、リポジトリには含めていません（`.gitignore`）。
